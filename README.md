# 📊 HR Analytics Dashboard – Excel

## 📌 Project Overview

This project is an interactive **HR Analytics Dashboard built using Microsoft Excel**.

The dashboard provides a clear overview of employee data and helps analyze workforce distribution, salary, experience, performance, hiring trends, and employee demographics.

## 📈 Dashboard KPIs

- **Total Employees:** 500
- **Active Employees:** 448
- **Inactive Employees:** 52
- **Average Salary:** ₹77,126
- **Average Experience:** 6.2 Years
- **Average Performance Score:** 7.5

## 📊 Dashboard Analysis

The dashboard includes the following HR analytics:

- 👥 Employees by Department
- 📍 Employees by Location
- 🔄 Employment Status – Active vs Inactive
- 💰 Average Salary by Department
- 📅 Employees by Experience
- ⭐ Average Performance Score by Department
- 📈 New Hires Trend by Year
- ⚧️ Gender Distribution
- 🏆 Top 5 Employees by Average Performance Score

## 🎛️ Interactive Filters

The dashboard includes interactive filters/slicers for:

- Gender
- Location
- Department
- Employment Status
- Joining Date

These filters allow users to dynamically analyze different segments of the employee dataset.

The objective of this project is to transform raw HR employee data into an interactive dashboard that provides useful insights into:

- Workforce distribution
- Employee salary patterns
- Department-wise performance
- Employee experience
- Hiring trends
- Gender distribution
- Employment status
- Top-performing employees
